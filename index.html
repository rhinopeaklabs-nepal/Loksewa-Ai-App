Core Feature

AI Learning Engine Pipeline

Unlike simple Q&A apps, the AI Learning Engine transforms every question into a complete interactive lesson with explanation, mnemonics, flashcards, and related questions.

Teaching Flow

1
User Scans Question
OCR extracts text from image, normalized for Nepali script
2
Find Verified Answer
Elasticsearch match with confidence scoring, source verification
3
User Clicks "Teach Me"
Triggers AI Learning Engine — never AI-generates answers
4
Context Retrieval
Topic notes, past questions, verified sources assembled
5
LLM Generates Lesson
Structured lesson with explanation, mnemonic, flashcards
6
Store & Cache
Saved to DB, flashcards created, Redis cached (24h TTL)

AI Lesson Structure

A
Simple Explanation
Teacher-style explanation in Nepali + English
B
Detailed Breakdown
Process, background, key features, sub-topics
C
Exam Notes
Loksewa-specific shortcuts and important points
D
Mnemonic
Memory aid to recall the answer easily
E
Related MCQs
AI-generated similar questions from same topic
F
Flashcards
Auto-generated cards for spaced repetition review

NEW — AI Learning Platform

→ Sees verified answer
→ Clicks "Teach Me"
→ Gets full AI lesson

Value: Understand, remember, revise, pass. Much higher retention and engagement.
