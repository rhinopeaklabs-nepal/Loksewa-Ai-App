# App Database Assets

Place the compressed seed database generated by `database/seed_script.py` in this directory.

Default runtime path expected by `lib/database_service.dart`:

```text
assets/loksewa_v1.db.gz
```

For Flutter, also register the file in `pubspec.yaml`:

```yaml
flutter:
  assets:
    - assets/loksewa_v1.db.gz
```
